## Веб-интерфейс

В корне проекта находится файл **`index.html`** — интерактивный графический веб-интерфейс для всех 12 лабораторных работ:
* Каталог со списком всех лабораторных работ в виде карточек.
* Страница каждой работы с полями для ввода исходных данных по каждой задаче.
* Кнопка «Вычислить» и мгновенный вывод результатов.
* Работает прямо в браузере (достаточно дважды кликнуть на `index.html` или открыть через Live Server в VS Code).

## Структура репозитория

* **`index.html`** — интерактивный веб-интерфейс со всеми задачами и формами ввода данных.
* **`Лаба 01. Линейные алгоритмы/`** — базовые вычисления (прямоугольник, окружность, треугольник по формуле Герона, евклидово расстояние, полиномы).
* **`Лаба 02. Алгоритмы ветвления/`** — условные конструкции `if-elif-else`, четверти плоскости, даты и числительные прописью, восточный календарь.
* **`Лаба 03. Циклические алгоритмы/`** — циклы `for` и `while`, накопление сумм и произведений, знакопеременные ряды, алгоритм Евклида.
* **`Лаба 04. Рекурсивные алгоритмы/`** — рекурсивные алгоритмы: факториал, Фибоначчи, степень, палиндром, рекурсивный бинпоиск, Ханойская башня.
* **`Лаба 05. Одномерные массивы/`** — массивы/списки, числовые прогрессии, чередующийся вывод, срезы, локальные максимумы, поиск дубликатов.
* **`Лаба 06. Двумерные массивы/`** — матричные операции, обход квадратной матрицы по спирали против часовой стрелки, суммы параллельных диагоналей, обмен четвертей.
* **`Лаба 07. Сортировка пузырьком/`** — пузырьковая сортировка с оптимизацией флагом `swapped`, пошаговой трассировкой и подсчетом операций.
* **`Лаба 08. Сортировка вставками/`** — сортировка вставками (Insertion Sort) со сдвигом элементов и замером числа сравнений.
* **`Лаба 09. Сортировка с выбором/`** — сортировка выбором (Selection Sort) с поиском минимума и минимизацией обменов.
* **`Лаба 10. Бинарный поиск/`** — двоичный поиск (итеративный и рекурсивный), пошаговое сужение диапазона, поиск диапазона повторяющихся элементов.
* **`Лаба 11. Работа с деревьями/`** — двоичное дерево поиска (BST), прямой (Pre-order), центрированный (In-order), обратный (Post-order) и поуровневый (BFS) обходы, псевдографика структуры.
* **`Лаба 12. Очередь/`** — реализация структуры данных Queue (FIFO) с ограничением вместимости и моделирование диспетчера веб-запросов.

## Запуск в терминале / VS Code

Каждая лабораторная работа поддерживает как **автоматическую демонстрацию**, так и **интерактивный ввод собственных данных**.

Для запуска скрипта перейдите в папку нужной лабы:
```bash
cd "Лаба 01. Линейные алгоритмы"
python3 main.py
```

После запуска программа предложит выбрать режим:
```text
1 - Запустить авто-демонстрацию всех задач
2 - Ввести свои данные для конкретной задачи
```
Все функции реализованы на стандартном Python 3 и не требуют установки внешних пакетов.
