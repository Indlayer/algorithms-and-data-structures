В данном репозитории представлены исходные коды выполненных лабораторных работ по курсу «Алгоритмы и структуры данных» (Линейные алгоритмы).

## Содержание

* **Лаба 1. Линейные алгоритмы** — вычисление геометрических характеристик (прямоугольник, окружность, треугольник по формуле Герона), евклидова расстояния и полиномиальных функций.
* **Лаба 2. Алгоритмы ветвления** — условные конструкции `if-elif-else`, определение координатных четвертей, текстовое представление дат и числительных, расчет года по восточному календарю.
* **Лаба 3. Циклические алгоритмы** — циклы `for` и `while`, накопление сумм и произведений, знакопеременные ряды без условных операторов, алгоритм Евклида.
* **Лаба 4. Рекурсивные алгоритмы** — рекурсивная декомпозиция: факториал, числа Фибоначчи, степень, проверка на палиндром, разложение на простые множители, Ханойская башня.
* **Лаба 5. Одномерные массивы** — работа со списками в Python, генерация числовых прогрессий, чередующиеся порядки вывода, локальные максимумы, поиск дубликатов.
* **Лаба 6. Двумерные массивы** — матричные вычисления, спиральный обход против часовой стрелки, перестановка четвертей матрицы, вычисление сумм параллельных диагоналей.
* **Лаба 7. Сортировка пузырьком** — классическая сортировка пузырьком (Bubble Sort) с оптимизацией флагом `swapped` и сбором метрик эффективности.
* **Лаба 8. Сортировка вставками** — реализация алгоритма сортировки вставками (Insertion Sort) со сдвигом элементов и подсчетом операций.
* **Лаба 9. Сортировка с выбором** — алгоритм сортировки прямым выбором (Selection Sort) с поиском минимума и минимизацией перестановок.
* **Лаба 10. Бинарный поиск** — двоичный поиск (итеративный и рекурсивный варианты), пошаговая трассировка, поиск диапазона вхождений элемента.
* **Лаба 11. Работа с деревьями** — двоичное дерево поиска (BST), прямой (Pre-order), центрированный (In-order), обратный (Post-order) и поуровневый (BFS) обходы, псевдографика структуры.
* **Лаба 12. Очередь** — реализация структуры данных Queue по принципу FIFO с защитой от переполнения и моделирование диспетчера веб-запросов.

## Запуск программ

Все программы разработаны на чистом стандартном Python 3 и не требуют установки внешних библиотек.

Запуск любой лабораторной работы:
```bash
cd "Лаба 1. Линейные алгоритмы"
python3 main.py
```
